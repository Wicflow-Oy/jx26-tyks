Strainwatch turns a hospital's microbiology results into a weekly, ward-level picture of antibiotic resistance: possible clusters, THL alert organisms, policy-line crossings and data gaps for infection control, and a flag on the drug a doctor is ordering when something is going on.

It runs on the laboratory's isolate export (here the challenge's synthetic Tyks dataset), with statistics and fixed clinical rules deciding, people approving, and a language model only allowed to word a message.

The core process

InputLab isolate export

Isolates with S/R per drug, ward, sample date and patient sex, age and home area.

RulesEffective results

EUCAST expected phenotypes, the MRSA cefoxitin screen and the local ESBL rule turn raw S/R into what counts.

DetectionStatistics, not prediction

Shared-antibiogram clusters with a rarity gate, THL rules, change tests and policy lines, strictly as of each week.

DecisionPeople decide

Infection control approves alerts; the order layer flags the doctor's drug and never names another one.

OutputText from counts

Every sentence is rendered from computed slots in English or Finnish; the model may only word the ED heads-up.

A clinical microbiologist must be able to trace every number back to its count, so the decisions sit in testable rules and statistics, never in a model's guess.

What we chose, and why

The model words, it never decides

Claude may only phrase the ED heads-up. It writes placeholders, code inserts the numbers, and a validator rejects digits and prediction words; any failure falls back to fixed text.

Checked against the raw data

Independent scripts re-derived the numbers on every screen from the CSVs, and 24 tests pin the headline numbers to that derivation.

The doctor decides

The order layer stays quiet by default, interrupts only at signing for an approved alert or the patient's own resistant result, and never recommends a drug.

Privacy and misuse

No identifiers reach the model, request bodies are never logged, the CSVs are never in git or downloadable, and writes are per session and rate-limited.

A demo that stays honest

Strict as-of: nothing after the chosen week changes its numbers. 101 weeks replay from a cache keyed to the code and data, on our own server in Helsinki.

Readable for everyone

English and Finnish with reviewed clinical terms, colour never the only signal on the heat map, keyboard use throughout, and layouts from 320 px up.
