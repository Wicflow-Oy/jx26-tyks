Antimicrobial resistance brief

The interface is on its way. The API is live; every view takes one as_of Sunday (or the brief's monday).

Endpoints

  • GET /api/health and GET /api/meta
  • GET /api/filters
  • GET /api/brief?as_of=&window=4w&rule=
  • GET /api/my-ward?as_of=&ward=&specimen=&organism=&sex=&age_band=&setting=&rule=
  • GET /api/trend?as_of=&ward=&specimen=&drug=
  • GET /api/replay/weeks
  • GET /api/feed?as_of=
  • GET /api/signals/{id}?as_of= (case file) and GET /api/second-opinion/{id}?as_of=
  • POST /api/alerts, GET /api/alerts?as_of=, POST /api/alerts/{id}/revoke
  • POST /api/heads-up, POST /api/heads-up/{id}/approve (never sent)
  • POST /api/narrate, POST /api/validate
  • POST /api/order-context, GET /api/patients/{id}/history?as_of=, GET /api/demo/scenarios
  • POST /api/order-feedback, GET /api/order-feedback/summary?as_of=, GET /api/feedback?as_of=
  • GET /cds-services, POST /cds-services/{id}, POST /cds-services/{id}/feedback (CDS Hooks 2.0)

Writes are kept per browser session (header X-Demo-Session). Nothing is ever sent.
